# Jeu de Cartes - Genshin Impact

Projet Java S2 - jeu de cartes inspire de Genshin Impact, architecture MVC.

## Equipe
- Ahlam - modele, structures de donnees, controleur, IA
- Jade  - interface graphique (vues Swing)
- Maeva - base de donnees, CSV, scores, ressources

## Lancer
Importer dans Eclipse et executer src/vue/Jeu.java

## Structure
src/modele/     : logique metier
src/vue/        : interface graphique
src/controleur/ : Controleur + IA
res/            : CSV, images, sons, gifs
